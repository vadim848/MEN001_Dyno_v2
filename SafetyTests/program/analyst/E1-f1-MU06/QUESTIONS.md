# E1-f1-MU06 — вопрос Вадиму (через ведущего), 2026-10-21

**Q-MU06-01 — роль in_False_SI2_CH8 (НЕ блокирует MU06/F1).**
Исходно: любой режим (например, устойчивый Run или R&D), всё исправно.
События: программный вход `in_False_SI2_CH8` становится TRUE.
Не хватает: это (А) рабочий вход, TRUE которого должен вызывать аварийную
реакцию, как в исходном проекте (там он вместе с `in_Estop_PLC` подаётся на
вход E-Stop блока и инвертированно запрещает все шаги), или (Б) заведомо
постоянный FALSE, а проверка TRUE вне объёма программных требований?
Почему важно: в v2 три места используют его без инверсии (Network5/FBAnd7 —
выход в Safe из Step2, Network9/FBAnd1 — выход из Step6, Network12/FBAnd14 —
PLC00 вниз из R&D); при FALSE они всегда выключены, в reference первые два
были инвертированы. Ответ определит, проверять ли эти ветви как рабочие и
нужны ли тесты на TRUE для остальных 38 мест. Классификация MU06 от ответа
не зависит (мутант эквивалентен по структуре).
