## Root cause
FBEstop1.Restart = V:in_Reset_PB. safeEstop (stand model, native falling-edge restart) enables on Restart 1->0 if Restart=1
was seen in a scan with all EStopIn safe. Green held in Safe through a 1-scan EStop pulse is seen =1 in the safe scans after
the pulse, so its release restarts (WARNINGS.md finding "out-of-scope observation"; identical in F1/reference).

## Design (2 FB, Network1, no Symbols, no timers)
| FB | fn | order (insertion) | inputs |
|---|---|---|---|
| Q62_RST | safeAnd | 41.5 (after HB_OK@41, before FBEstop1@42) | AndIn1 V:in_Reset_PB NC; AndIn2 !W:Q62_BLK.RsOut (NO) |
| Q62_BLK | safeRs  | 42.1 (right after FBEstop1@42)            | Reset !V:in_Reset_PB (NO); Set G:b_EStop_Ok NC |
Changed: FBEstop1.Restart V:in_Reset_PB -> W:Q62_RST.AndOut (NC). Port id kept, only usage retargeted.

Semantics: Q62_BLK (reset-dominant, like all program RS) = 1 iff the current green press has had a scan with
b_EStop_Ok=1 (pressed outside Emergency); cleared on release. Restart := green AND NOT BLK(previous scan).
- Green held from Safe -> BLK=1 -> Restart stays 0 through the pulse and the release -> no falling edge -> stays Emergency.
- Press begun in Emergency (b_EStop_Ok=0 every scan of the press) -> BLK=0 -> Restart = green -> unchanged native edge.
- Boot: b_EStop_Ok=0 from scan 1 -> green held at power-up counts (BOOT-002/B-02 unchanged).
- Exit scan e: green already 0 -> BLK Reset dominant -> BLK=0; no spurious edge. BLK rising while green held happens
  only with b_EStop_Ok=1 (already Safe) -> Restart falling edge in Safe is a no-op.
- Boundary: press rising on the same scan as the EStop pulse counts (BLK samples b_EStop_Ok after FBEstop1 = 0);
  press started >=1 scan before Emergency does not. Model-only, scanMs 1.

Input rule: in_Reset_PB is a safe alias (device 62, A12 SI2 EL1918, standard=false); b_EStop_Ok, Q62_* are safe FB
outputs. No standard signal involved. NO contact on safeRs.Reset has 12 precedents (CFG_EX, STATE_A, WDC1_*...).
Last-cycle read: one new backward wire Q62_BLK.RsOut -> Q62_RST.AndIn2, intentional (press history). It feeds only
FBEstop1.Restart (exit path). FBEstop1 EStopIn1..8 untouched -> Emergency entry latency unchanged.
