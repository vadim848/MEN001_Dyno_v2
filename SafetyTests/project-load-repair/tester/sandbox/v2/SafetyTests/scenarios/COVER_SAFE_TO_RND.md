# COVER-SAFE-RND-01 — открытие крышки и новый переход в R&D

Покрывает требования C01, C05, C06 и C08 из `SAFETY_TEST_PLAN.md`.

| Время/этап | Green | Blue | CoverClosed | CoverLocked | LV feedback | Ожидаемое состояние | Ожидаемые действия |
|---|---:|---:|---:|---:|---:|---|---|
| Начало | 0 | 0 | 1 | 1 | 0 | Safe | Unlock=0, LV=0, STO=1 |
| 0–2.0 s | 0 | 0 | 1 | 1 | 0 | Safe | Выполняется release filter |
| 2.0–2.9 s | 0 | 1 | 1 | 1 | 0 | Safe | Unlock=0: `T_SINGLE` ещё не завершён |
| 2.9–3.0 s | 0 | 1 | 1 | 1 | 0 | Safe | На границе 3.0 s Unlock становится 1 |
| Открытие | 0 | 1 | 0 | 0 | 0 | Safe | Unlock=1, fault отсутствует |
| Отпускание Blue | 0 | 0 | 0 | 0 | 0 | Safe | Unlock немедленно 0 |
| Ожидание 60 s | 0 | 0 | 0 | 0 | 0 | Safe | Нет timeout/fault; крышка может оставаться открытой |
| Новая попытка StepUp | 1 | 1 | 0 | 0 | 0 | Safe | После фильтров импульс потреблён, но переход игнорируется без fault |
| Полное отпускание | 0 | 0 | 0 | 0 | 0 | Safe | Начинается новый release filter |
| Ручное закрытие | 0 | 0 | 1 | 1 | 0 | Safe | Сам feedback не запускает переход |
| Новый StepUp | 1 | 1 | 1 | 1 | 0 | StartingRnD | Unlock=0, LV command=1 |
| LV feedback | 0 | 0 | 1 | 1 | 1 | R&D | Переход завершён |

Обязательные отрицательные проверки:

- `UnlockCover` не появляется до окончания `T_SINGLE`;
- открытая крышка не создаёт timeout/fault в Safe;
- StepUp с открытой или незапертой крышкой не включает LV;
- закрытие крышки не восстанавливает ранее отклонённую команду;
- во время `StartingRnD` соленоид разблокировки выключен;
- `R&D` не устанавливается до появления LV feedback.
