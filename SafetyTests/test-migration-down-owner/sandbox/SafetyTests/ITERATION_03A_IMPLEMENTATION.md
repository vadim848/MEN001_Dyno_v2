## Доработка по независимому R1

Ревью выявило риск false PASS будущей импульсной реализации: наблюдение
только в конце999/1100мс могло пропустить запрещённый импульс раньше конца.
Добавлен общий scan-observer: каждый скан считывается, наличие хотя бы одного
TRUE сохраняется до конца интервала. EXACT:CHORD/FLICKER, REARM shortneutral,
REPEAT и fresh-release prethreshold теперь проверяют все сканы запретного
интервала. Положительные проверки1000/1001мс сохранены. Ранее LATE cases уже
наблюдали каждый скан; их смысл не менялся.

Две отдельные harness-проверки доказывают обнаружение1мс импульса в середине
999/1100мс и продолжение полного исполнения после обнаружения. Конечный
выход emitter FALSE: прежнее наблюдение только в конце дало бы ложный PASS.
Это проверка наблюдателя стенда, не подмена приёмки рабочего SAL.
