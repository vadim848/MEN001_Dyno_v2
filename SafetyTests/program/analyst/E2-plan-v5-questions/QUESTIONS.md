# E2-plan-v5-questions — вопросы (v2-analyst, 2026-10-22)

Новых вопросов Вадиму в этом срезе нет.

- R5-1 по HV закрыт ответом Вадима на вопрос 73 «А» (вопрос задавала родительская сессия). Критерий DIS-HOLD-HV — READY.
- Пограничные пункты решены по D-TEAM-DEFAULTS. Они записаны в SCENARIO_DECISIONS.md, раздел «Решено командой», статус «ждёт просмотра Вадимом»:
  - TD-01 — LV Discharge снимается в момент принятия Safe→R&D;
  - TD-02 — верхняя граница подтверждения Run/R&D: K+101;
  - TD-03 — STO при h > e;
  - TD-04 — нажатие в том же скане, где FBK стал OFF.
- Все четыре решения TD:
  - не добавляют энергию и не снимают защиту;
  - не противоречат ответам Вадима;
  - не меняют интерфейс PLC/оператора.

  Поэтому сразу спрашивать Вадима не нужно. Ведущему: передать пакет TD Вадиму на просмотр перед переносом среза.

Для сведения ведущего (это не вопросы):
- Предусловие SPEC §7 «discharge request снят» в R&D→Run буквально расходится с Q-V7-01 «Г»: запрос держится до принятия перехода. Действует более поздний ответ Вадима — 73 «А», снятие в момент принятия. Расхождение текста SPEC — в журнал изменений спецификации.
- В reference запрос снимается при подъёме: после включения контакторов, но до снятия STO. В v2 STO снимается в момент принятия (D-STO-LAUNCH). С ответом 73 «А» перекрытие «STO снят ∧ запрос» остаётся только в сканах [a, u].
