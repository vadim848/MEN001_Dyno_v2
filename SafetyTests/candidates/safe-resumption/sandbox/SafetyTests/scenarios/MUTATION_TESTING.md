# MUTATION-TESTING — проверка чувствительности тестов

Команда:

```powershell
npm run test:mutations
```

Скрипт сначала требует успешный baseline, затем для каждого дефекта создаёт временную копию `SafetyTests` в системной временной папке. Рабочая эталонная модель и TwinSAFE не изменяются. После прогона временная копия удаляется.

| ID | Искусственный дефект | Какой класс тестов обязан упасть |
|---|---|---|
| M01 | C2 отключается до окончания discharge | Инвариант discharge/C2 и сценарии F/G |
| M02 | Потеря Healthy во время SS1 игнорируется | F02 |
| M03 | Разрешён StepUp с открытой крышкой | C06 и полный сценарий крышки |
| M04 | TwoButtonsAttempt деградирует в синюю одиночную команду | B09/B11 |
| M05 | Run объявляется без `C2_FBK=ON` | E04 и тесты перехода вверх |

Критерий успеха: каждый mutant должен быть обнаружен минимум одним падающим тестом. Выживший mutant означает пробел в тестовом покрытии или эквивалентное изменение и требует анализа.
