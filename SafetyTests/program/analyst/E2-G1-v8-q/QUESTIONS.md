# E2-G1-v8-q — вопросы

Вопросов Вадиму нет. Проверка по D-TEAM-DEFAULTS п.4:

| Решение | Добавляет энергию / снимает защиту | Противоречит ответу Вадима | Меняет интерфейс PLC/оператора |
|---|---|---|---|
| TD-11 (HV Discharge в SU до подъёма HV — без нижней границы) | нет: допускает только более ранний разряд при уже активном STO и C2 OFF | нет (Q-V7-01 «Г», вопрос 73 «А» — порядок соблюдён; Q-ARCH-01 — таймеры не меняются) | нет |
| TD-12 (нижняя граница L1 в SU d_Run−2; C1 ≥ 2000 мс) | нет: только более раннее снятие энергии на 1 скан, 2 с C1 сохранены | нет (Q-ARCH-01, Q-E2Q-01 «через 2 с») | нет |
| TD-13 (a := A в REL01-e2-LATE) | нет: Emergency обязательна, повышение запрещено | нет (Q-RC-03(a), Q-RC-14) | нет |
| FFS-BYP (Bypass не обходит крышку) | нет | нет (V14-Q16, CFG-001) | нет |

TD-11 и TD-12 — явные ослабления oracle, в пакет Вадиму перед переносом среза.
Положительное поведение Config (V14-Q16) — BLOCKED-E4, вопросы по нему не задаются до новой документации.
