# Пакет S2 (E2) для просмотра Вадимом — перед переносом в canonical

Дата: 2026-10-23. Ведущий. Только программная модель стенда: не Verify/Build/Target, не аппаратная безопасность.

## Кандидат

- **E2e r2**: `SafetyTests/candidates/E2e/native` — SAL `67336d9b…`, SGVL `4d68adb3…`, diagram `31e516fe…`; 239 FB (≤ 512), native CRC valid.
- База: E2d v7.7 (`c2f9ccd7…`, заморожен). Canonical F1 (`04b45456…`) не менялся.
- План: `program/architect/E2-S2/PLAN.md` (acdb9819…) + `PLAN_ADD_D04.md` (ea6b43e9…). Реализация: `program/editor/E2e/IMPLEMENTATION.md`.

## Исправлено (5)

1. L3: снятие энергии в Emergency из Run опаздывало на 2 скана — порядок исполнения (N8/FBOrS5).
2. E2-02: восстановление LV в спуске → теперь R&D, затем цепной R&D→Safe (память HLT_MEM, сброс в Safe).
3. Выход из Emergency при C1/C2_FBK ON запрещён (в т.ч. FBK ON во время удержания зелёной).
4. R&D/outPLC_RnD не раньше команды C1 + 500 + 100 мс (WIN_C1 от команды C1).
5. D-04 (найдено каталогом): зелёная 0,5 с в Safe→R&D — abort в Safe (C1 OFF), без возобновления.

- Мутации M: 11 убиты; M-12 (D-02) — оценим только в E3.
- Ревью: `program/reviewer/S2/REVIEW.md` — код ACCEPT; тесты дополнить B1 (D-08 возврат LV до C2_FBK OFF), B2 (E-05 Emergency из Safe с FBK ON).

## Решения команды на просмотр (REC-ACCEPTED / TD)

Полный текст — `SafetyTests/SCENARIO_DECISIONS.md`.
- **TD-02…TD-15** (2026-10-22): скановые допуски/меры принятия; по D-COMPACT как oracle силу потеряли (TD-02, -03, -06, -08…-12, -15), суть — в каталоге. TD-04, TD-05, TD-07, TD-13, TD-14 — поведенческие (TD-05: legacy Safe→R&D не исполняется в Emergency; TD-14: StartingRun — фаза внутри R&D).
- **G3Q-1**: явное ослабление L2 на 1 скан (в ±50 мс не действует). **G3Q-2**: L3 не ослаблять (исправлено, п.1). **G3Q-3**: 1-скановая потеря LV в спуске запоминается (исправлено, п.2).
- **REC-ACCEPTED**: f=R исполняется (XPH-01); перенос recRndC_SU в GATE_PHASE на первый путь SU→R&D (E3/E4/E6).
- **S2-TD (новые)**: S1-Q1 W-05 через фронт PLC; S1-Q2 Discharge Request после старта = FALSE (как reference); S1-Q3 Restart до конца аварийной цепи (~8 с) теряется, нужно новое нажатие; S1-Q4 D-04 = этап E2; S1-Q5 SafetyFault NV до E5; S4(b) не дефект E2.
- Прочее: в каталоге 88 строк, а не 100 (опечатка итога).
