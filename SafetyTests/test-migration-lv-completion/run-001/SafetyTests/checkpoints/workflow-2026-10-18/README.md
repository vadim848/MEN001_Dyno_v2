# До первой итерации workflow

`baseline-results.json` / `.md` — пакет до исправлений. `manifest.json`
фиксирует HEAD и SHA256 незакоммиченных исходников стенда. `baseline-sources.zip`
сохраняет src/scripts/test/fixtures/package.json и требования в момент запуска.
Новые результаты сюда не записывать: это снимок до изменений, не latest report.

Для воспроизведения в отдельной временной копии v2 распаковать архив; каталоги
src/scripts/test/fixtures и package.json разместить в SafetyTests, спецификацию
и тест-план — в корне. Рабочий SAL восстановить в этой временной копии из
SafetyTests/fixtures/v2-4bb8703/TwinSafeGroup1.sal. Reference по identity из
manifest/результатов должен быть доступен по ожидаемому соседнему пути для
сравнительных проверок; отсутствие будет отмечено явно. Выполнить в SafetyTests
`npm run check:software`. Ожидается exit 1 и 108 PASS / 62 FAIL / 3 NOT VERIFIED,
при доступном исходном reference; время отчёта может отличаться.

Не восстанавливать этот снимок поверх рабочего проекта; он предназначен для
независимого воспроизведения. SAL не продублирован текстом: его точная fixture
в архиве и в репозитории, SHA256 указан в manifest.
