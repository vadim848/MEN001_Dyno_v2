# Дайджест действующих решений (указатель к SCENARIO_DECISIONS.md)

Сверено с SafetyTests/SCENARIO_DECISIONS.md на 2026-10-22 (после TD-15, Q-V7-04).

**Как пользоваться.** Это навигация, не норматив. Источник истины —
`SafetyTests/SCENARIO_DECISIONS.md`. Для oracle, критерия, плана или ревью
по конкретному ID откройте именно его раздел: `Grep "^### <ID>"` или `Grep "<ID>"`
с `-A 30`, а не весь файл (≈180 КБ). При любом расхождении прав полный файл.
Если ID здесь нет, ищите grep'ом в полном файле. Отсутствие в дайджесте
не означает, что решения нет.

**Поддержка.** Тот, кто записывает новое решение или пересмотр в SCENARIO_DECISIONS
(аналитик или ведущий), в том же шаге добавляет или правит здесь одну строку.
Заменённое помечается «→ заменено X» и удаляется при следующей чистке.

Обозначения: **В** — прямой ответ Вадима; **TD** — решение команды
(D-TEAM-DEFAULTS), ждёт просмотра Вадимом, в тестах источник «TEAM-DEFAULT TD-xx».

## Кнопки и жесты

- **D-TIMING / п.1–2** (В): single зелёная/синяя — 0,5 с непрерывно; BOTH — 1 с от второй.
- **D-CHORD250 / п.3, п.6** (В): вторая кнопка ≤ 250 мс (включительно), симметрично; > 250 мс — BOTH не принимается.

- **п.7** (В): отпускание одной кнопки в BOTH до 1 с не превращается в single.
- **п.9** (В): пауза перед новой попыткой — обе отпущены непрерывно 2 с.
- **Q-REL-AFTER-PERMIT** (В): пауза 2 с считается только по кнопкам; кратковременная потеря разрешения её не сбрасывает (поведение F1 изменить; MU24 перепроверить).

- **п.12** (В): зелёная = `in_Reset_PB` → Network1/FBEstop1.Restart; это существующая функция, не новое правило Emergency→Safe.

## Аварийная цепь и Emergency

- **Q-ARCH-01** (В): авария при LV ON/HV OFF (R&D, R&D→Safe, Safe→R&D) — общая цепь как в Run: сразу C3/BMS OFF + LV discharge, C1 OFF через 2 с (**Q-E2Q-01**), затем STO/HV discharge/C2 OFF; после Restart только Safe.
- **Q-T3-1** (В): авария во время спуска — каждый шаг не позже нормального момента: min(нормальный, аварийная цепь).
- **E2** (В): двойное владение стадиями исключить по построению; обнаруженный конфликт → Emergency. **Q-RC-10** (В): ни одного основного состояния → Emergency.
- **Q-RC-19** (В): подтверждённый FBK C1/C2 пропал при команде ON → Emergency (везде). **Q-V4-01**: «подтверждён» = после окна 500 мс от команды ON; внутри окна провалы не авария.
- **Q-MU06-01/02** (В): `in_False_SI2_CH8` — технический константный FALSE (NC-обход); три ветви без инверсии (N5/FBAnd7, N9/FBAnd1, N12/FBAnd14) отключены намеренно, инверсию не возвращать.

- **Q-V4-02** (В): FBK ON без команды (Safe, R&D-C2) → SafetyFault + запрет подъёма до FBK OFF. **Q-V7-04**: нажатие при активной причине не квитирует. **TD-04** (TD): нажатие в скане g, где FBK стал OFF, — наблюдение.
