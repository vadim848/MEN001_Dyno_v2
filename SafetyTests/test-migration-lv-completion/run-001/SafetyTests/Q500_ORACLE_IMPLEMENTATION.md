# D-Q500 — синхронизация oracle

Историческая подитерация: последующее решение D-CHORD250 заменило окно500мс
на250мс включительно. Решение о single на500мс сохраняется, но это уже вне
окна комбинации. Актуальный oracle и результаты: SCENARIO_DECISIONS.md и
SOFTWARE_CHECK_RESULTS.md; этот отчёт не переопределяет последующие решения.

2026-10-18. Решение пользователя: одиночная команда уже должна быть
квалифицирована на 500мс. Вторая кнопка ровно500мс не превращает эту попытку
задним числом в StepUp. Симметрично для blue-first и green-first.

SAL и его параметры не изменялись; SHA256 остаётся
`74896fb6b3c08d829cb3bea8e7a7c0452ffde4b09ad262043f463f9ff4b10a5c`.

В candidate-button-cover.js проверяются обе очередности на490/500/510мс,
после2100мс обеих отпущенных кнопок. Up допускается только при490мс;
на500/510мс запрещён и на1000, и на1010мс совместного удержания.
Реальная Network12 пока не имеет полного Armed recognizer: neutral —
заданная начальная последовательность, а не доказательство корректного rearm.

Перед второй кнопкой отдельно наблюдается реальный TON первой: FALSE при490,
TRUE при500/510. Этот witness подтверждает время квалификации компонента,
но не подменяет отсутствующее отдельное событие принятия single. Во время
совместного удержания отдельно проверяется отсутствие конечного unlock во
всех сканах: green его запрещает. Длительность видимого blue pulse в
граничном скане не назначается новым требованием.

Historical runner ожидает FAIL для дефектной fixture EDGE и сохраняет
проверку мутации0.5→1с как FAIL. Добавлена проверка наличия обеих очередностей
и distinctqualification/output observations. Ожиданияrelease2с,
запрет деградации failedchord и остальные сценарии не ослаблялись.

Полный `npm run check:software`: harness71/71, historical75/75,
current6/6; cases116 PASS /57 FAIL /3 NOT VERIFIED /0 ERROR, exit1.
По сравнению с предыдущим запуском +3FAIL отражают новый охват и исправленный
oracle: EDGE green-first сталFAIL, добавлены EDGE/LATE blue-firstFAIL.
IN обеих очередностей PASS; четыре EDGE/LATE случая честно показывают

Полный recognizer, самостоятельный acceptanceevent и произвольные повторные
попытки остаются вне доказательства этих шести компонентных сценариев.
Готово к независимому ревью; дальнейшая запись остановлена.
